# Katagun

Shezhire of the Qataghan tribe (Қатаған). The site is [katagun.com](https://katagun.com).

Qataghan is also written Katagan and Katagun. The page is in Kazakh, English, and Russian. Kazakh names are the source. English and Russian are letter-by-letter transliterations of that one tree.

A solid line is father to son. A dotted line runs from the tribe name to the oldest known ancestors: Күлдір, Дүрмен, Мамай, and Шаңышқылы.

## Local

```bash
python3 -m http.server 8753
```

Open [http://127.0.0.1:8753/](http://127.0.0.1:8753/). The page needs a local server. Opening `index.html` as a file will not load the diagram.

People and parent links live in `tree.js`. Notes for editing the page are in `AGENTS.md`.
